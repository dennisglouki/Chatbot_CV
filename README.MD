This RAG chatbot was developed as a simple portfolio demostration of an end-to-end project.
It allows recruiters to dig deeper, explore my CV, get familiar with my projects, and ask questions on my past research.
It will be continously improved and extended.

The backend was developed by me. It uses gemini-3.8-flash as an LLM model, that generates answers taking into account the actual content of my CV, and my research papers.

The front end was copied and adapted from:
